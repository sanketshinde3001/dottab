2.0.0 · September 2026

The first DotTab release on the Chrome Web Store.

  • 28 widgets on a 32-column grid that scales from a laptop to a 4K screen; narrow windows fold into one column.
  • Dot-matrix design — dark and light themes, none / outline / card surfaces, focus mode.
  • Command palette (Ctrl K) with !bangs, maths, URLs and every action.
  • Presets & share codes — Dashboard, Minimal, Productivity, Playground, Everything; send a layout as a short code.
  • Pixel pet that walks on your widgets and remembers where it stood.
  • Backups — export and import everything as one JSON file (Settings → About).
  • New: Greeting, Headlines, Ticker, Tetris, Typing Test, Decide, Top Sites.
